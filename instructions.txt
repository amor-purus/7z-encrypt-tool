7z 文件加密工具 v1.0.3 使用说明

一、安装与启动
1. 安装 64 位 CPython 3.14。
2. 将项目解压到一个有写入权限的文件夹。
3. 双击 start.bat。
4. 启动器会尝试识别常见的 Python 3.14 安装位置，包括传统安装器、Python Install Manager 和部分全局安装路径。
5. 启动器会检查 CPython、3.14 版本、64 位架构、虚拟环境对应的基础解释器，以及 py7zr 是否严格等于 1.1.4。
6. 首次运行需要联网安装依赖，只允许使用预编译 wheel，不会尝试本机 C++ 编译。
7. GUI 启动后，黑色命令窗口会自动退出，不需要一直保留。

二、使用方法
1. 点击“选择要加密的文件”。
2. 选择一个或多个文件。
3. 选择输出文件夹。
4. 等待压缩和安全校验完成。
5. 输出文件夹中会出现一个 .7z 和一个同名 .txt。

三、这次修复的内容
- 修正归档命名：重名文件会补充父目录，且不会抢占后面唯一文件的名字。
- 防止归档中出现同一路径重名，以及一个文件同时被当成另一个文件的目录。
- 归档名称按 Windows 大小写不敏感规则检查。
- 对重复选择、符号链接和可识别的硬链接去重。
- 加密完成后先验证无密码无法读取文件名，再用正确密码核对成员列表并执行完整性检查。
- TXT 会记录原始文件名与归档内路径的对应关系。
- 先发布密码 TXT，再发布正式压缩包，避免正式压缩包先于密码记录出现。
- 加密和校验期间，GUI 会阻止正常关闭操作；后台任务使用非守护线程。
- GUI 通过 pythonw 启动，关闭命令窗口不会中断已经启动的 GUI 任务。
- 启动器会检查 py7zr 的确切版本，并检查虚拟环境是否残缺或引用了错误的 Python。

四、重要提醒
- TXT 中保存的是明文密码，请单独保管，不要和 7z 一起发送给不应知道密码的人。
- 如果输出目录位于 WPS 云盘、OneDrive 或其他同步目录，TXT 和 7z 可能一起被同步上传。
- 原文件不会被删除、移动或修改。
- 加密期间请勿通过任务管理器强制结束程序，也不要关机。

五、可选测试
在项目目录打开命令窗口，运行：
.venv314\Scripts\python.exe -m unittest discover -s tests -v

测试覆盖归档路径冲突、唯一文件名保护、符号链接去重，以及系统支持时的硬链接去重。实际加密、独立 7-Zip 解压验证和 Windows 图形界面仍应先用不重要的测试文件确认。
