7z 文件加密工具 v1.0.2 使用说明

这次修正版的关键变化：不再通过 py -3.14 选择 Python，而是直接调用安装器默认目录中的 python.exe，避免再次误用 Python 3.15。

一、先不要使用旧文件夹
1. 关闭之前打开的黑色命令窗口。
2. 在桌面新建一个空文件夹，例如：7z_encrypt_v102。
3. 下载并解压本 ZIP 到这个全新的文件夹。
4. 不要从以前解压的 v1.0 或 v1.0.1 文件夹启动。

二、启动
1. 双击 start.bat。
2. 启动器会直接检查这个路径：
   %LOCALAPPDATA%\Programs\Python\Python314\python.exe
3. 控制台应显示：
   Base runtime: 3.14.10
   Architecture: 64 bit
   Private runtime: 3.14.10
4. 首次运行会联网安装依赖。
5. 安装只允许下载预编译 wheel，不会调用 C++ 编译器。

三、这次具体修复了什么
- 不再调用 py -3 或 py -3.14，避免 Python Launcher 选错解释器。
- 使用 Python 3.14 安装器默认路径中的 python.exe。
- 新建独立 .venv314，不会复用旧版 .venv（例如 Python 3.15 环境）。
- 安装前和安装后都会显示实际 Python 版本及完整执行路径。
- 如果不是 64 位 Python 3.14，会停止，不会继续安装。
- pip 使用 --only-binary=:all:，没有 wheel 时直接停止，不尝试源码编译。

四、重要判定
如果窗口显示的 Base runtime 或 Private runtime 不是 3.14.x，或者安装记录里出现 cp315，请立即停止并把整个窗口内容发回来。正确运行时应看到 cp314，不应出现 cp315。

五、功能与安全
- 选择一个或多个文件，然后选择输出文件夹。
- 创建一个文件名和目录名均加密的 7z。
- 自动生成32位随机密码及随机压缩包名。
- 同目录生成 TXT，记录原文件名、压缩包名、密码、文件名是否加密。
- 原文件不会被删除、移动或修改。
- TXT 中有明文密码，请与 7z 分开保管。

首次请用不重要的测试文件验证压缩和解压。
