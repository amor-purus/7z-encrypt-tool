7z 文件加密工具 v1.1.0 使用说明

一、下载与启动
1. 打开本仓库的 Releases 页面。
2. 下载 7z-encrypt-tool-windows-x64.exe。
3. 双击 EXE 即可打开图形界面。
4. 不需要安装 Python，不需要 start.bat、虚拟环境、pip，也不需要管理员权限。
5. 选择要加密的文件，再选择输出文件夹。
6. 等待“正在加密打包”和“正在校验文件头加密和压缩包完整性”两个阶段完成。

如果暂时没有正式 Release：
1. 打开 GitHub 仓库的 Actions 页面。
2. 选择 Build standalone Windows EXE。
3. 打开最新一次成功的运行记录。
4. 在 Artifacts 区域下载 7z-encrypt-tool-windows-x64-提交号。
5. Artifact 默认保留 30 天。打上 v 开头的版本标签后，构建产物还会自动附加到 GitHub Release。

二、Windows SmartScreen 提示
本程序目前没有代码签名证书，因此 Windows 可能显示“Windows 已保护你的电脑”或“未知发布者”提示。

请只在以下条件全部满足时考虑继续：
- 文件来自本仓库官方 Actions Artifact 或 Release。
- 文件名与预期一致。
- 使用 SHA256SUMS.txt 核对 SHA-256 校验值一致。

如果 SmartScreen 提供“更多信息（More info）”和“仍要运行（Run anyway）”，并且设备管理策略允许，可以选择继续。不要为了运行来源不明的文件而关闭 SmartScreen 或杀毒软件。如果公司或学校设备禁止未签名程序，请联系管理员获取批准版本。

PowerShell 校验命令示例：
(Get-FileHash .\7z-encrypt-tool-windows-x64.exe -Algorithm SHA256).Hash

三、主要功能
- 使用 7z AES-256 加密。
- 加密文件头，隐藏压缩包内的文件名和目录名。
- 自动生成 32 位随机密码和随机压缩包名。
- 同时生成 TXT，记录密码以及原始文件名到压缩包内部路径的对应关系。
- 对重复选择、符号链接和可识别的硬链接去重。
- 无密码读取文件头验证、正确密码成员清单核对、CRC 完整性检查。
- 不删除、不移动、不修改原始文件。
- 加密或校验期间不允许正常关闭窗口。
- 支持日文及其他 Windows 显示语言，并允许调整窗口大小。

四、重要安全提醒
1. TXT 中保存的是明文密码，请与 7z 分开保管。
2. 如果输出位置属于 OneDrive、WPS 云盘或其他同步目录，7z 和密码 TXT 可能一起被上传。
3. 不要通过任务管理器强制结束正在处理的程序。
4. 单文件 EXE 首次启动时需要在临时目录展开内置运行环境，因此第一次启动可能稍慢。

五、日志位置
程序日志位于：
%LOCALAPPDATA%\7z-Encrypt-Tool\logs\application.log

遇到错误时，可检查这个日志。日志可能含有本机文件路径，分享前请先检查内容。

六、开发者构建说明
源代码构建依赖写在 requirements.txt 和 requirements-build.txt。
PyInstaller 配置为：
- 7z-encrypt-tool.spec
- pyinstaller_hooks\hook-py7zr.py
GitHub Actions 会在 Windows x64 环境执行源码测试、生成单文件无控制台 EXE，并直接运行 EXE 自检。
